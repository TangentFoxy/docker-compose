# Yamtrack
A multimedia tracker.

Modified from [readme](https://github.com/FuzzyGrim/Yamtrack) instructions which tell ya to use the [dev docker-compose.yml](https://github.com/FuzzyGrim/Yamtrack/blob/dev/docker-compose.yml).

**WARNING**: Yamtrack, despite having a nicer aesthetic, the ability to add custom items, and being more updated, is inferior to MediaTrack in speed, usability, and presentation &amp; availability of information.
